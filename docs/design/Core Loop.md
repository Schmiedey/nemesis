# Core Loop

1. Survive a ~2 minute top-down run. Movement only; aim is automatic.
2. Kill enemies, collect gems, level up, pick 1 of 3 upgrades.
3. Die. The enemy type that landed the killing blow joins your side permanently.
4. Next run starts with your roster of nemeses fighting for you.

Planned (council): recruits are earned by survival time, you draft 3 per run, and the killer inherits the build you died with. See [[Council Verdict]].
New enemy types unlock as runs last longer (0:20, 0:45, 1:15, 1:45, 2:20).
